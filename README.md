# PDF to Excel Converter

A Python script that extracts numerical data from PDF files and saves them into a structured Excel file.

## Features
- 📄 Reads PDF files (text-based)
- 🔢 Extracts all numbers using Regular Expressions
- 📊 Saves data into Excel with two sheets:
  - **Numbers**: All extracted numbers
  - **Summary**: Total, average, max, min
- 🛠️ Includes a sample PDF generator for testing
